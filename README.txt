T-CITY ADMIN v0.2 — CRM / T-БОНУСЫ / ДНИ РОЖДЕНИЯ

Собрано поверх утверждённого ADMIN v0.1.
Визуальный принцип сохранён: чёрный/белый, строго, без интро, сразу рабочая панель.

1. АКТУАЛЬНАЯ ДАТА И ВРЕМЯ
- ADMIN показывает текущее время T-CITY в часовом поясе Тюмени (Asia/Yekaterinburg, UTC+5).
- Раздел «Сегодня» больше не подменяет текущую дату старым демо-днём.
- Демо-записи автоматически создаются относительно реального сегодняшнего дня.

Пока сервер не подключён:
источник момента времени = часы устройства, отображённые как Тюмень.

После backend:
источник истины = сервер.
События хранятся в UTC, бизнес-расписание отображается по Тюмени.
Ни телефон клиента, ни телефон ADMIN не будут определять время базы.

2. ЗАВЕРШЕНИЕ ВИЗИТА
Статусы работы:
Ждём вас → В работе → Готов.

После «Готов» появляется отдельная кнопка:
ЗАВЕРШИТЬ ВИЗИТ

Она означает: автомобиль выдан клиенту.

После завершения:
- запись исчезает из «Сегодня»;
- попадает в историю визитов клиента;
- увеличивает общее количество обслуженных автомобилей;
- сумма входит в статистику;
- рублёвая часть добавляется в финансовый доход;
- применённые T-Бонусы списываются;
- 5% от рублёвой части начисляется клиенту на T-Бонусы.

3. РАЗДЕЛ «ЗА ВСЁ ВРЕМЯ»
Отдельный пункт главного меню:
- автомобилей обслужено;
- выручка за всё время;
- средний чек.

Считаются только завершённые визиты.

4. VIP
В профиле каждого клиента есть ручной переключатель VIP.
Никакой автоматики — VIP выдаёт только владелец T-CITY лично.

5. ДАТА РОЖДЕНИЯ
В профиле клиента добавлено поле «Дата рождения».

ADMIN автоматически создаёт уведомление:
- «Завтра день рождения»
или
- «Сегодня день рождения».

Для демонстрации у Александра Первушина день рождения выставляется на завтра относительно даты запуска демо.

Нажатие на уведомление открывает готовый экран поздравления:
- готовый текст;
- можно изменить текст;
- можно написать подарок свободным текстом;
- можно подарить любое количество T-Бонусов;
- отправка сохраняет поздравление в истории уведомлений клиента;
- T-Бонусы реально добавляются в его локальный демо-кошелёк.

6. T-БОНУСЫ В ADMIN
У каждого клиента:
- баланс;
- история;
- начислено;
- списано;
- ручное начисление;
- ручное списание.

Правило визита:
5% начисляется только на сумму, оплаченную рублями.

7. СЕРВИСНЫЕ НАПОМИНАНИЯ
В карточке клиента появился отдельный таб «Напоминания».
Можно создать:
- дату;
- произвольный текст.

Когда дата наступает, ADMIN создаёт уведомление.
Нажатие переводит сразу в готовую персональную рассылку клиенту.

Для теста у Марии Соколовой есть напоминание на текущий день.

8. ЧТО ЕЩЁ НЕ СВЯЗАНО
Это по-прежнему локальный прототип:
- клиентское приложение и ADMIN имеют разные localStorage;
- реальной общей базы ещё нет;
- уведомления между телефонами реально не отправляются;
- Telegram ID пока не является ключом профиля.

Следующий этап после утверждения двух приложений:
SERVER + BACKEND + DATABASE + синхронизация CLIENT ↔ ADMIN.


9. УДАЛЕНИЕ АВТОМОБИЛЯ
В карточке автомобиля клиента появилась кнопка:
«УДАЛИТЬ АВТОМОБИЛЬ».

Логика:
- требуется отдельное подтверждение;
- если на автомобиль есть активная запись, удалить его нельзя;
- сначала нужно отменить или завершить активную запись;
- после удаления автомобиль исчезает из Garage клиента;
- история уже завершённых визитов сохраняется;
- общая статистика и выручка за прошлые визиты не теряются;
- сервисные напоминания, привязанные именно к удалённой машине, удаляются.
